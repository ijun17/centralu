# centralu-win32-x64

The Windows (x86-64) app for [Centralu](https://github.com/ijun17/centralu), shipped as a
portable folder: `Centralu\centralu.exe` beside `Centralu\resources\host\`.

**Do not install this directly** — the `centralu` package pulls it in as an optional
dependency and picks the right build for your machine.

```powershell
npm i -g centralu
centralu
```
