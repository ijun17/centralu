# Worktrees

A session in a git worktree of its own: made on a new or an existing branch, set up (copied files, an install
command), shown with its merged and pull-request state, archived with a recovery snapshot and restored, removed, and
swept at start when a removal left part of one. Rules:
[delegation/child-workspace.md](../agent-host/delegation/child-workspace.md),
[delegation/worktree-recovery.md](../agent-host/delegation/worktree-recovery.md).
