# Working in this repository

Rules for coding agents (Claude Code, Codex and others). They are the rules people follow;
this file only points at them. Read these before your first change:

- [CONTRIBUTING.md](CONTRIBUTING.md): language, what has to pass, tests, commits and pull
  requests, and **running things safely** (real data, running processes, e2e, OS prompts).
- [docs/commit-conventions.md](docs/commit-conventions.md): commit messages.
- [docs/README.md](docs/README.md): the map of design documents. When a change moves the
  design, fix the document in the same pull request; if they disagree, the document is wrong.

Talk to the person in whatever language they use. Everything written down (code, comments,
tests, documents, commits, issues, pull requests, reviews) is in English.
